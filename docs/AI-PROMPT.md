# 交給其他 AI 的提示詞

先將 [格式規格](AI-JSON-GUIDE.md) 與 [範例專案](../examples/example-project.json) 附給 AI，將下方整段提示詞複製過去，再替換最後的設計需求。
若 AI 無法讀取網址，請直接上傳兩份檔案，或貼上其內容。

```text
我想為 Visual Page Builder 產生一份可匯入的網頁設計專案。

請先閱讀我附上的：
1. AI-JSON-GUIDE.md：這個編輯器的專用 JSON 規格。
2. example-project.json：正確結構的參考範例。

請嚴格依照規格，將下方需求轉成 version 1 的專案 JSON。

要求：
- 輸出可下載的 UTF-8 design.json。
- 如果無法提供檔案，請輸出一個完整 JSON 程式碼區塊。
- JSON 裡不要加註解、尾逗號或省略號。
- 不要輸出 HTML、React 或任意 JavaScript。
- version 必須是數字 1；root.id 必須是 root；root.tag 必須是 main。
- 其他元件 ID 使用 el-數字，必須唯一；所有互動引用的 ID 必須存在。
- 只能使用規格允許的元件、屬性、CSS 與互動動作。
- CSS 屬性使用 kebab-case，值使用字串。
- 設計必須考慮桌面、平板與手機。
- 不要使用遠端圖片 URL 或外部資源；需要圖片時先使用有背景色的區塊替代，除非我提供合規的圖片 data URL。
- 不支援的部分請在 JSON 外另外說明，不要自行發明欄位。
- 輸出前，請自行核對 JSON 結構、所有 ID、互動目標與格式限制。

我的設計需求：
【在這裡描述網站內容、配色、版面和互動，或說明要參照的截圖／HTML】
```

## 設計需求範例

```text
我要一個咖啡店首頁：
- 米白色背景、深咖啡色文字。
- 頂部是店名和導覽。
- 中間是大標題、介紹文字與預約按鈕。
- 下方是三張商品介紹卡片。
- 手機版改成單欄。
- 點預約按鈕後，顯示「請來電預約」的文字。
- 先不使用圖片。
```

## AI 回傳後

1. 取得 `.json` 檔案；若只有程式碼區塊，複製區塊內的 JSON，另存成 UTF-8 的 `design.json`，不要包含 ``` 標記。
2. 先在編輯器按「儲存專案 JSON」備份目前作品。
3. 按「載入專案 JSON」，選擇 AI 產生的檔案。
4. 檢查桌面／平板／手機，並用「操作預覽」測試互動。
5. 若匯入失敗，把錯誤訊息、原 JSON 與規格交回 AI 修正。若能匯入但外觀不符，描述實際差異；匯入器會清除部分不支援的欄位，匯入成功不等於所有內容均被保留。
